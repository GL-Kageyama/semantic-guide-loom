# 評価の記録

この作品の台本は、書いては評議会（`novel-council-layer` の 8 次元評価）に掛け直す往復で磨いた。
**採用したのは、頂点の 1 本だけ**。ほかの版はここに残してあるが、映像には使わない。

## 採用版

[`../台本.md`](../台本.md) — **v7（平均 67.25）**。合格ラインは 60。

評価後に、事実の精度だけ 5 語直してある（`裁定所` ×2・`2025年7月の、あの話`・`報告されて、いる`・`1万7千回`）。
文の運びと台詞は v7 のまま。

## 置き場

```
review/
  README.md      このファイル
  facts.md       事実確認の記録（根拠と注意書き）
  drafts/        v1〜v9 の本文（評価に渡した形）
  reports/
    v4/ v5/ v6/ v6-single-model/ v7/ v9/
```

`reports/*/` は評価者の JSON をそのまま置いている。`facts.md` には、
どの記述が一次資料で、どれが報道ベースか、どれが演出かを書き分けてある。
