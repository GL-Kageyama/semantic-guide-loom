# 評価の記録

台本は、書いては評議会（`novel-council-layer` の 8 次元評価）に掛け直す往復で磨いた。
**採用したのは、平均が最も高い 1 本**。ほかの版はここに残してあるが、映像には使わない。

## 採用版

[`../台本.md`](../台本.md) — **v1（平均 76.75）**。合格ラインは 60。

評価後に、事実の精度だけ 1 行落としてある（`7日間。宇宙で、直す。`）。
STS-61 の実際の期間とも合わず、`design.md` の事実の柱にも無いため。
文の運びと台詞は v1 のまま。

## 採点の推移

8 次元の平均。評価者は版ごとに独立して招集した。

| 版 | 平均 | 採否 | 何をしたか |
|---|---:|---|---|
| **v1** | **76.75** | **採用** | 初稿 |
| v2 | 70.50 | 不採用 | 紙の折れ端を立て、`覚えが、ある` を植え、説明の行を削った |
| v3 | 66.75 | 不採用 | 長い息を 2 本、定規を実際に使う場面、退けられた検査の具体化 |

v2 と v3 は、評価が重なった弱点（一律の断句・説明過多）を直すために書いたが、
平均は v1 を超えなかった。**直した版が、必ずしも上がらない**ことを示す記録として残す。

### 版ごとの内訳

| 次元 | v1 | v2 | v3 |
|---|---:|---:|---:|
| hook | 87 | 79 | 62 |
| plot-architecture | 83 | 83 | 83 |
| reader-experience | 75 | 62 | 66 |
| prose-style | 71 | 69 | 62 |
| admiration | 80 | 76 | 67 |
| anti-generic-story-filter | 74 | 49 | 48 |
| theme-resonance | 74 | 78 | 71 |
| emotional-power | 70 | 68 | 75 |

v1 と v2/v3 の anti-generic の差（74 対 48〜49）は、本文の差だけでは説明できない。
評価者を替えたときのばらつきが、`docs/` の想定（±3 点）より大きい。採否は平均で決めたが、
この差は評価の限界として記録しておく。

v3 の theme-resonance は、最初の JSON が `value_vector_contribution` に存在しない次元
（`reader_experience:null`）を含んでいたため `engine/review.py validate` が弾いた。
同じ評価者にエラーを添えて 1 回だけ採り直し、71 点（初回 77 点）を記録した。
