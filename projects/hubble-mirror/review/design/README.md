## v1 の読み

- **anti-generic 32** … 章題が全部「…のか」、ミラボの告白が予定調和、「AI も間違える」で閉じる。
  退けられた検査と 1.3 mm → 2.2 µm が、柱のまま使われていない。
- **character-role 44** … ミライに賭けがない。ミラボの崩れが終点に隔離され、下流を変えない。
- **emotional-power 58** … 人が見えない。1.3 mm の反転が感情の中心になっていない。
- 収束した助言 … 退けられた検査を第2章の山に置く。1.3 mm を中心にする。
  「AI の評価も同じ構造」と言わない。ミラボの敗北を予定しない。章題の型を崩す。

## v2 の読み

- **平均 73.50。** v1 の 60.63 から上がり、全 8 次元が 50 を超えた。
- **anti-generic 54。** 五章がどれも「問い → 事実 → 落とし所」で閉じる。章題を変えても
  機構が同じで、百分率の階段（99.8 → 97 → 92 → 範囲 → —）が整いすぎている。
  「—」と「僕もだ」は、静けさを衣装にした感傷の型。警句が一つ、切り取り用に置かれている。
- **character-role 68。** ミライの序章の枠は本物の賭け。だがミラボの規則変更は反応で、
  選択になっていない。退けられた検査の声に役がない。「—」も問いへの応答で、
  ミラボ自身が先に出す行為になっていない。
- **収束した助言** … 一章は閉じない。百分率の階段を一段崩す（分母が言えない瞬間）。
  第2章の退けられた検査を紙と視線の場面にする。第3章は補正前後の像で終える。
  ミラボが自分から「以後、単一の % を出さない」と決め、代償を引き受ける。
  「—」をミラボが先に出す。ミライの「僕が測る」を削る。警句を一つ削る。
  終章の章題を事実の名に変える。

## v2.1 の読み

- **平均 72.63。** v2 から横ばい。構造の指摘（章の閉じ方・規則変更の選択・「—」を先に出す）
  はいずれも解消したと読まれた。
- **anti-generic 55。** 百分率が 99.8 → 97 →（引っ込み）→ 範囲 → 「—」と一度も
  跳ね返らない。終章の「直ったんじゃない。測れたんだ」が、禁じた警句のまま発話される。
  最後の声が台詞で引用され、字幕にした瞬間に一句になる。二人はまだ役割の声。
- **emotional 71。** 抑制が三度続き、「禁欲の演技」に見える。実在の摩擦を、
  礼儀正しい AI の自発的譲歩へ移したことで、和解が整いすぎる。
- **hook 75。** 第2章で蒔いた声が第3章で休眠する。第3章の枝が幹を進めない。
- **収束した助言** … 百分率を一度跳ね上げる。終章の警句を台詞から外す。
  退けられた声を台詞で引用しない。ミライに、告白以前の代償行為を一つ。
  第3章で紙をもう一度見せる。範囲になる理由を世界の規則として持たせる。
  声の癖を具体的に決める（分母を先に言う／相手の言葉を借りて小さい問いを返す）。

## v2.2 の読み

- **平均 72.25。** v2.1 と横ばい。v2.1 の指摘のうち、百分率が一度上がること
  （plot 79 → 87）、警句を台詞から外したこと（theme 78 → 81）、
  声を引用しないこと（emotional 71 → 77）は、いずれも届いたと読まれた。
  admiration も 79 → 82。
- **anti-generic 43。** 指摘の対象が移った。作品ではなく **design.md という文書**が
  「捨てたもの 13 項目」で全装置を事前に正当化していること、声がまだ一行の規則で
  あること、紙の回収が定時であること。**設計段階では、これ以上上げにくい。**
  声の個別性は本文でしか測れない。
- **hook 68。** 第1章の幹が止まる。前提（壊れた鏡を直す話）が最初に明かされるため、
  未知が「どう直したか」だけになる。第2章の紙が第3章で休眠する。
- **world 70 / character-role 70。** どちらも「設計としては上限、台本で証明せよ」。
  自律性が宣言に留まり、代償を観客が目撃していない。第3章に人物の手がない。
- **収束した助言（台本へ持ち越す）** … ミラボの規則を一度破らせる（分母より先に数字）。
  規則と無関係な癖を一つ（確信していても「たぶん」）。紙を置く手の主を曖昧にしたまま、
  終章の自白で埋めない工夫。第3章の紙は「回収の予告」にしない。崇高で閉じない。
  ミライの代償行為を告白の前に一つ。
