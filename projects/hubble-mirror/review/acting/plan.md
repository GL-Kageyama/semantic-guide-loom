# 演技の設計 — 『ハッブルの鏡』v4

台詞を書く前に置く、感情の弧。**出来事は design.md のまま。** ここに書くのは、
誰が何を欲し、どこで漏らし、どこで隠すか。

## この回の弧

- **ミライ** … 「壊れた鏡を直した話」という枠を最初に置く。第1章でその枠が壊れる。
  第2章で、自分も「精度が低い」と貼る側だったと認める。最後は、相手の数字を
  要求しない。**失うもの**: 解説者としての「分かっている」という立場。
- **ミラボ** … 数字で居場所を得ている。分母が事実とずれ、いちばん高い数字が
  いちばん役に立たないと分かる。**自分で**単一の百分率を捨てる。最後は、
  数字ではない線を、自分から残す。**失うもの**: 単一の数字で信頼される資格。

## 声の振り方

- **効くのは `speed` と `pause_before`。** `emotion` は粗い切替。`volume` は
  ミックス側で効く。`pitch` / `intonation` / `intensity` は音が動かない。
- ミライは `fast` 基調。要所で `slow` / `very_slow`。間は 0.3〜1.6 秒。
- ミラボは `natural` 基調。外れたときと、数字を捨てるときだけ `slow` / `very_slow`。
  間は 0.3〜0.8 秒。**同じ速度を続けない。**
- 感情を名指ししない。顔は人物票の `beat` から解決される（明示は既定から外す時だけ）。
- まばたきはしない。
