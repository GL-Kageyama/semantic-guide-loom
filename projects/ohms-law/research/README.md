# 調査 — オームの法則

「オームの法則」の学習用動画の台帳。設計・台本・詳細カードは、ここに置いた事実だけを言う。
**焼く時に検索しない。**

## 範囲

- オームの法則の内容（電流と電圧の比例、抵抗の定義、単位）
- オームの実験（1826年、銅線、熱電対、ねじり秤）
- オームの経歴と評価（1827年の本、1841年コプリーメダル、1881年の単位）
- オームの法則が成り立たない例（白熱電球、LED）
- オーム抵抗と、LED の直列抵抗
- 中学校学習指導要領での扱い

## 範囲の外

- 量子ホール効果によるオームの実現（2019年以降の SI）。今回は扱わない。
- 交流回路のインピーダンス。今回は扱わない。
- オームの法則の微視的な導出（ドルーデ模型）。今回は扱わない。
- 直列・並列の合成抵抗の計算。今回は「触れる」程度で、主役にしない。

## 正本

- **`facts.yaml`** — 映像で言ってよい事実。1 fact = 1 つの主張。
  `details[].fact` はこの id を引く。カードの文は fact の範囲を出ない。
- **`sources.yaml`** — 出典。`facts.yaml` の `sources` はこの id を引く。
- **`notes/<source-id>.md`** — 出典ごとの抜き書き（要旨・単位・分母）。
- **`queries.md`** — 検索語、当たった資料、訂正、分からなかったこと。

`review/facts.md` は台本の門の記録で、カードの正本ではない。

## 更新の仕方

1. 新しい主張は、先に `sources.yaml` と `notes/` を足す。
2. `facts.yaml` に 1 fact を足す。事実と解釈を分ける。作品内の値は `kind: in-work`。
3. `video.yaml` の `details[].fact` を合わせる。
4. `engine/scriptcheck.py --project projects/ohms-law --strict` で参照切れを見る。
