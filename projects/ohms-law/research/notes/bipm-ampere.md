# bipm-ampere — SI base unit: ampere

- 出典: https://www.bipm.org/en/si-base-units/ampere
- 取得: 2026-11-10
- 確度: 高

## 要旨（引用ではなく要約）

- アンペアは、電気素量 e = 1.602176634×10⁻¹⁹ C を固定して定義される。
- 1アンペアは、1秒に 1/(1.602176634×10⁻¹⁹) 個の電気素量が流れる電流。
- クーロンは C = A·s。

## 使う所

- **今回の台本では使わない。** 2019年SIの話は範囲の外。
- 将来「単位の現在地」を足すときの控え。
