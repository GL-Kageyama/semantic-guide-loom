## v6 の変更（評価点のためではなく、作品のため）

- 序章に、封筒・金曜の締切・他人の名前の投稿予告を置いた。優先権の圧を、終盤の説明ではなく最初の物で置く。
- 第1章の返却論文は、付箋を剥がしていない物体として残した。
- 章末を束・封筒へ戻した（「束を、閉じる」「封筒に、入れる」）。
- 「出す」の反復を減らし、動作に置き換えた。
- ミラボの撤回理由を、GRHを仮定した評価の上に載る暗号の一部へ具体化した。
- 数字・英字・記号の読みを `reading.yaml` に固定した。
- TTS の「すうは→かずは」を避けるため、「双子素数は」は漢字で固定。
- 地の文・動作を narrator（画面に居ない語り手）へ移した。画面の二人は沈黙し、字幕だけが残る。
- 中央パネルに詳細カードを18枚追加（範囲・上限・条件付き定理・RSA・4段階・クレイ賞）。`fact` は research/facts.yaml の id を引く。
