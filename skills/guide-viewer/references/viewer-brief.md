## 返答の形

**JSON だけ**を返してください。前後に説明を書かないでください。

```json
{
  "reader_id": "r1",
  "prior_knowledge": "none",
  "summary": "出来事の要約（5文以内）",
  "numbers": {
    "99.8%": "何を測った数字か。分からなければ「分からない」"
  },
  "cause": "原因。台本が明示している範囲で",
  "fix": "どう直したか。台本が明示している範囲で",
  "recovered": {
    "<問いの id>": "yes / partial / no"
  },
  "unclear": [
    {"line": "意味が取れなかった行（そのまま引用）", "why": "何が分からなかったか"}
  ],
  "clarity": 0
}
```

- `recovered` は、**あなた自身の判定**です。問いの id ごとに、
  台本だけから答えられたなら `yes`、半分なら `partial`、答えられなければ `no`。
- `unclear` は最大 10 個。**行をそのまま引用**し、分からなかった点を一言で。
- `clarity` は台本全体の「意味の取りやすさ」を 0〜100 で。
  100 は、予備知識のない人が一度で因果を追える。40 は、雰囲気は分かるが
  何が起きたか復元できない。
