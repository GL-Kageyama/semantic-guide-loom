# 読みの罠

`draft` は fugashi（unidic-lite）で漢字を開く。**機械が間違える所**を、人が見る。
確認は `engine/reading.py audit --phonemize --cue <cue>` の音素で行う。

## 月日

| 表記 | 正しい読み | 機械がやりがち |
| --- | --- | --- |
| 四月 | しがつ | よんがつ |
| 七月 | しちがつ | なながつ |
| 九月 | くがつ | きゅうがつ |
| 一日 | ついたち | いちにち |
| 二日 | ふつか | ににち |
| 三日 | みっか | さんにち |
| 四日 | よっか | よんにち |
| 五日 | いつか | ごにち |
| 六日 | むいか | ろくにち |
| 七日 | なのか | ななにち |
| 八日 | ようか | はちにち |
| 九日 | ここのか | きゅうにち |
| 十日 | とおか | じゅうにち |
| 十四日 | じゅうよっか | じゅうよんにち |
| 二十日 | はつか | にじゅうにち |
| 二十四日 | にじゅうよっか | にじゅうよんにち |

`draft` は上の表を先に当てる。ただし **`一日中`（いちにちじゅう）** のように、
日付でない `一日` は残す（`中・半・間・分・後・前・目` が続くときは直さない）。
文脈で迷ったら、その cue だけ音素を見る。

## 数

| 表記 | 読み | 注意 |
| --- | --- | --- |
| 一人 | ひとり | いちにん ではない |
| 二人 | ふたり | ににん ではない |
| 二十歳 | はたち | にじゅっさい ではない |
| 一万人 | いちまんにん | 数字のままでも読めるが、読みを固定すると安定 |
| 1万7千回 | いちまんななせんかい | 数字は `needs_review` に出る |
| 0.1% | れいてんいちぱーせんと | `%` は `ぱーせんと` |
| 97% | きゅうじゅうななぱーせんと | 文脈で「きゅうじゅうなな」 |
| 100% | ひゃくぱーせんと | |

**アラビア数字は、`draft` が触らずに残す。** 年号・百分率・回数・金額で読みが違う。
`needs_review` の cue を、上から順に決める。

## 固有名・外来語

- `AI` → `えーあい`（`エーアイ` でもよい。読みを固定する）
- `ChatGPT` → `ちゃっとじーぴーてぃー`
- `Transformer` → `とらんすふぉーまー`
- `OpenAI` → `おーぷんえーあい`
- `Air Canada` → `えあーかなだ`
- 人名は、日本語で定着した読みを使う。迷ったら音素で確認する。

## 漢字の熟語

- **世界の見方** → せかいの **みかた**（みほう、ではない）
- **行方** → ゆくえ（ぎょうほう、ではない）
- **灯火** → ともしび
- **一手** → いって（ひとて、ではない）
- **現在地** → げんざいち
- **本番** → ほんばん

`audit` は、読みに漢字・数字・`%`・Latin が残っている cue を警告する。
警告がゼロでも、**同音異義の誤読**（見方／みほう）は残り得る。`--phonemize` で確かめる。

## 直し方

- `reading.yaml` の `readings.<cue>` を、かなで書く。
- 句読点・`……`・`？`・`！` は残す。間と抑揚はそこから作られる。
- 字幕は触らない。字幕は `script.yaml` / `video.yaml` が持つ。
