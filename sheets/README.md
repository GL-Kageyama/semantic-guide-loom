# sheets/ — 表情シートの置き場

置いてあるのは `casts/<名前>.cast.yaml` が名前で指す PNG だけ。**Git LFS で配布する**
（`.gitattributes` の `*.png`）。clone したら `git lfs pull` で降りてくる。

```
sheets/ミライ_表情差分シート.png
sheets/ミラボ_表情シート.png
```

## 要る形

- **4列×2行 = 8 マス**。左から右、上の行が先。
- **背景は透過**（RGBA）。白を抜く処理はしていない。
- 8 マスとも**同じ位置・同じ大きさ**で描かれていること。`prepare_assets.py` は
  外接矩形の上端と横中心でそろえるが、目と口の位置が大きく違うと口パクが崩れる。
- 表情の並びは `casts/<名前>.cast.yaml` の `expressions` が書く（シートは順番だけ持つ）。

## 口パクは絵から測る

`prepare_assets.py` は**口を消さない**。唇の線を 1 マスずつ拾い、その線の**下に**
口の中を描き足す。座標は手で書かず、目の中心を 8 マスから測って（中央値＋外れ値の
除去）、`mouth_offset` を足して口の位置を出す。

**シートを差し替えたら `mouth_offset` を測り直す。** 目から口までの距離は絵ごとに違う。
`prepare_assets.py` は各マスの `pt` と唇の線の範囲を標準出力に出すので、
口パクがずれたらその数字を見る。

## なぜ入れるか

表情シートは**入力**であって派生ではない。`prepare_assets.py` が作る切り抜き
（`build/`）はシートから戻せるが、**切り抜きからシートは戻せない**。落とすと
`dialogue-bust` は焼けなくなる。

2 枚で約 3.3 MB。`.gitattributes` の `*.png` が LFS に載せるので、履歴は太らない。
